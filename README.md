# darts-arrange
- https://unaya11.github.io/darts-arrange/
## 主な機能と仕様
### アレンジ検索
#### 170以下の場合
- 入力された数字から3本で上がるアレンジを出力します。
  - 1投目・3投目に投げたい数字をチェックボックスで指定ができます。（複数指定可）
  - 指定がない場合は全ケースの出力を行います。
#### 171以上の場合 
- 上がり目が出る場合はそのアレンジを出力します。
  - 上がり目が出ない場合は出力されません。
  - チェックボックスの指定は反映されません。
### 出力について
- 2本目にダブルを用いたアレンジは出力対象外となっています。ただしインナーブルは出力対象となっています。
- ダブルアウトのみ対象となり、3本目は1-20のダブル、もしくは50のケースが出力されます。
- 3本で上がるケースのみ出力されます。
